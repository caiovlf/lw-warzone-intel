04 / METHOD

How the new ranking works

1. Combine season points

Read the NvSP, NvEM and WaE lists. Normalize names for accents, spacing and decorative characters, then review distinctive OCR substitutions. Associate each row with a current UID. Add all associated row scores for that UID, including scores earned on multiple lists. Do not add the separately saved NvSP backup a second time.

2. Measure participation and performance

Participation = player points / all uploaded points × 100. This denominator includes unmatched points so the known shares are not inflated. The performance index is the player's season-point percentile among scored eligible candidates. High is the upper third (index ≥66.67), Medium the middle third (≥33.33), and Low the lower third.

3. Rank with 70/30 weights

Fit score = 0.70 × THP percentile + 0.30 × points percentile. Both indexes range from 0 to 100 among the same scored eligible candidates; ties use average positions. This makes the requested weights comparable without mixing raw THP and points units. Kills have no role in this calculation.

Source: the uploaded last_war_defeat_season_rankings_ALL.csv (NvSP), the NvEM CSV, and the WaE CSV found alongside it. The first source column identifies the score list; the separate Alliance column identifies the actual alliance. If Alliance is blank, use the saved API or inferred historical origin. Conflicting nonblank Alliance values require resolution. THP and total kills come from the saved 8 October API response or the last valid saved kill reading. The uploaded points have no dated daily series, so they measure season contribution rather than weekly consistency.
